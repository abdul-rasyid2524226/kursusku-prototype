## 1. Tujuan Praktikum

Praktikum ini bertujuan untuk memahami penerapan dasar
pemrograman PHP dalam pengembangan prototype website.

## 2. Hal yang Dipelajari

Beberapa materi yang dipelajari dalam proyek KursusKu:

- Penggunaan variabel dan tipe data PHP.
- Penggunaan operator aritmatika dan logika.
- Pengolahan string.
- Penggunaan fungsi dan prosedur.
- Pengolahan tanggal dan waktu.
- Pembuatan kalkulator biaya kursus.
- Pengujian fungsi program.
- Penggunaan GitHub untuk menyimpan kode proyek.

## 3. Kendala

Dalam pengerjaan proyek, diperlukan ketelitian saat membuat
file, menulis kode, dan menyimpan perubahan ke repository.
Pemeriksaan kembali juga diperlukan untuk memastikan setiap
file berada di lokasi yang benar.

## 4. Solusi

Pengerjaan dilakukan secara bertahap dengan memeriksa nama file,
isi kode, dan hasil perubahan pada GitHub.
Pengujian program perlu dilakukan melalui server PHP untuk
memastikan program berjalan sesuai harapan.

## 5. Kesimpulan

Proyek KursusKu menjadi latihan untuk menerapkan konsep dasar
PHP, mengorganisasi file proyek, serta mendokumentasikan
proses pengembangan menggunakan GitHub.

## 6. Evaluasi Diri

Hal yang perlu ditingkatkan adalah kemampuan memahami kode PHP,
melakukan pengujian mandiri, dan menyusun dokumentasi proyek
secara sistematis.
