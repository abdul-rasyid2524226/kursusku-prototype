## 1. Tujuan Praktikum

Praktikum ini bertujuan untuk memahami dasar-dasar pemrograman web menggunakan PHP, HTML, dan CSS. Praktikum juga melatih kemampuan dalam membuat fungsi, menggunakan percabangan dan perulangan, mengolah data, serta melakukan pengujian program.

## 2. Materi yang Dipelajari

Materi yang dipelajari dan diterapkan dalam proyek KursusKu meliputi:

1. Penggunaan variabel dan tipe data PHP.
2. Operator aritmatika, perbandingan, dan logika.
3. Percabangan menggunakan `if`, `elseif`, dan `else`.
4. Perulangan menggunakan `foreach`.
5. Pengolahan string dan tanggal.
6. Pembuatan fungsi menggunakan `function` dan `return`.
7. Pemisahan fungsi bantuan ke dalam file `helpers.php`.
8. Pembuatan halaman web menggunakan HTML dan CSS.
9. Pengujian fungsi menggunakan data aktual dan hasil yang diharapkan.
10. Pengelolaan proyek menggunakan GitHub.

## 3. Penerapan pada Proyek KursusKu

KursusKu merupakan prototipe katalog kursus online yang dibuat menggunakan PHP. Proyek ini memiliki halaman katalog kursus, informasi mahasiswa, waktu server, kalkulator biaya, serta halaman pengujian berbagai konsep dasar PHP.

Fungsi bantuan digunakan untuk memformat harga dalam Rupiah, menghitung total biaya, menghitung diskon, dan menentukan status kursus.

Proyek juga dilengkapi gambar katalog dan video pengenalan sebagai bagian dari antarmuka.

## 4. Kendala dan Solusi

Salah satu kendala dalam mengerjakan proyek adalah memahami sintaks PHP dan hubungan antara kode PHP dengan HTML. Kendala lainnya adalah mengatur struktur file proyek dan memahami proses pengujian fungsi.

Solusi yang diterapkan adalah mempelajari kode secara bertahap, memisahkan fungsi bantuan ke dalam file tersendiri, serta menggunakan GitHub untuk menyimpan dan mengelola perubahan kode.

## 5. Hasil Pembelajaran

Melalui proyek ini, saya mempelajari cara menyusun halaman web menggunakan PHP, mengolah data, membuat fungsi yang dapat digunakan kembali, serta menyusun contoh pengujian program.

Saya juga memahami pentingnya dokumentasi dan pencatatan hasil pengujian agar proyek lebih mudah diperiksa dan dikembangkan.
